# 上帝模式使用指南 (God Mode User Guide)

## 📖 概述

上帝模式（God Mode）是修仙世界模拟器中的高级功能，允许你作为"天道"直接干预世界的运行。通过上帝模式，你可以：

- 🤖 使用AI助手生成内容
- ⚡ 施展神力干预角色命运
- 🌍 控制世界规则和事件
- 📜 追踪所有干预行为的历史

## 🚀 如何使用

### 访问上帝模式

1. 启动游戏后，按 `ESC` 键打开系统菜单
2. 点击 **"🌟 上帝模式"** 标签
3. 在上帝模式面板中选择你想要的功能

### 功能详解

## 🤖 AI助手功能

### 1. AI文本生成

使用免费AI模型生成任意文本内容。

**使用步骤：**
1. 在"提示词"输入框中输入你的需求
2. （可选）在"上下文"输入框中提供背景信息
3. 勾选"使用快速模型（免费）"以使用免费AI
4. 点击"生成"按钮

**示例提示词：**
- "生成一个修仙世界的门派介绍"
- "创作一段关于筑基期修士的对话"
- "描述一个秘境的场景"

### 2. AI建议角色事件

为选定角色生成适合其境界和性格的事件建议。

**使用步骤：**
1. 从下拉列表中选择一个角色
2. 点击"获取AI建议"
3. AI会根据角色的境界、门派、性格等信息生成合适的事件建议

**应用场景：**
- 不知道如何推动角色剧情时
- 想要为角色安排有趣经历
- 寻找灵感触发世界事件

### 3. AI生成剧情

为多个角色生成互动剧情。

**使用步骤：**
1. 选择1-5个角色（可多选）
2. 选择事件类型（奇遇、战斗、情缘、突破、探险）
3. 点击"生成剧情"

**事件类型说明：**
- **奇遇**：角色遇到意外机缘或神秘事件
- **战斗**：角色之间或与外敌的战斗场景
- **情缘**：角色间的情感互动
- **突破**：角色境界突破的戏剧性场景
- **探险**：角色共同探索未知区域

## ⚡ 神力干预功能

### 1. 赐予机缘

为选定角色赐予各种恩赐。

**机缘类型：**

| 类型 | 说明 | 数值范围 |
|------|------|----------|
| 经验值 (EXP) | 增加修炼经验，有助于境界提升 | 100-10000 |
| 灵石 (Magic Stone) | 增加角色的灵石财富 | 100-10000 |
| 生命值 (HP) | 恢复角色生命值 | 100-10000 |

**使用步骤：**
1. 选择要赐予的角色
2. 选择机缘类型
3. 使用滑块调整数值
4. 点击"赐予"按钮

**效果：**
- 角色获得相应资源
- 系统生成"天道垂怜"事件
- 记录在历史中

### 2. 降下天劫

对角色施加天劫考验。

**使用步骤：**
1. 选择要考验的角色
2. 使用滑块调整天劫难度（1-10级）
3. 点击"降下天劫"按钮

**难度说明：**
- **1-3级**：轻微考验，造成少量伤害
- **4-6级**：中等天劫，对角色有一定威胁
- **7-10级**：严重天劫，可能危及生命

**效果：**
- 角色受到伤害（伤害 = 最大HP × 难度 × 10%）
- 系统生成"天降异象"事件
- 记录在历史中

⚠️ **注意**：过高难度的天劫可能导致角色死亡！

### 3. 触发世界事件

创建自定义的世界事件。

**使用步骤：**
1. 在文本框中输入事件描述
2. （可选）选择相关角色
3. 勾选"重大事件"使事件在历史中更显著
4. 点击"触发事件"按钮

**事件描述示例：**
- "天空出现异象，七彩霞光笼罩整个修仙界"
- "秘境开启，无数修士蜂拥而至"
- "魔族入侵，正道各派紧急集结"

**提示：**
- 重大事件会在事件面板中特别标注
- 关联的角色会在事件中被提及
- 可以配合AI生成的剧情使用

## 📜 历史记录

历史记录标签页显示所有上帝模式的操作记录。

**记录内容：**
- 操作时间
- 操作类型（能力名称）
- 操作描述
- 操作结果
- 是否使用AI

**特殊标记：**
- 🤖 标记表示该操作使用了AI
- 边框颜色：
  - 蓝色边框：使用AI的操作
  - 灰色边框：常规操作

**刷新历史：**
点击"刷新"按钮可以重新加载最新的历史记录。

## 💡 使用技巧

### 1. 结合使用AI和干预功能

推荐工作流程：
1. 使用"AI建议角色事件"获取灵感
2. 根据AI建议，使用"赐予机缘"或"降下天劫"实施
3. 使用"AI生成剧情"创作相关故事
4. 用"触发世界事件"把剧情加入世界

### 2. 平衡游戏体验

- **适度干预**：过多干预可能破坏世界的自然演化
- **观察影响**：通过历史记录追踪你的干预效果
- **尊重规则**：虽然是上帝，但也要考虑世界的内在逻辑

### 3. 创造故事

上帝模式非常适合用来：
- 推动停滞的剧情
- 创造戏剧性转折
- 测试"如果...会怎样"的情景
- 帮助喜欢的角色渡过难关

## ⚙️ 技术说明

### AI模型选择

**快速模型（免费）：**
- 响应速度快
- 适合简短文本生成
- 建议用于日常交互

**智能模型（按需）：**
- 生成质量更高
- 适合复杂剧情创作
- 成本相对较高

### API配置

上帝模式使用游戏主LLM配置。确保在"LLM设置"中正确配置了API。

### 性能考虑

- AI生成可能需要几秒钟
- 干预操作即时生效
- 历史记录限制显示最近50条

## 🐛 常见问题

**Q: 为什么AI生成失败？**
A: 检查LLM配置是否正确，API密钥是否有效。

**Q: 天劫会杀死角色吗？**
A: 是的，过高难度（8-10级）的天劫可能导致角色死亡。

**Q: 历史记录会保存吗？**
A: 历史记录在游戏会话期间保存，但不会持久化到存档文件中。

**Q: 可以撤销上帝操作吗？**
A: 不能直接撤销，但你可以通过相反操作来补偿（如赐予生命值恢复天劫伤害）。
